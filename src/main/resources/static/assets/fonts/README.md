# Fonts

## Arabswell

Arabswell Regular is the approved Moroccan display face for large Arabic
headings and party names. Its canonical browser asset is the checksum-versioned
object documented in `scripts/verify-web-fonts.sh`; do not replace that object
in place. Embedded metadata identifies the family as `arabswell_1`, foundry
`MZ73`, with unrestricted embedding (`fsType = 0`).

## Tajawal

Fhemni uses checksum-versioned GCS copies of Tajawal Regular, Medium and Bold
for Arabic body text and interface controls. The repository copies preserve an
offline source for builds and tests. Tajawal was designed by Boutros
International and is distributed under the SIL Open Font License 1.1. See
`TAJAWAL-OFL.txt` in this directory for the complete license.

## Noto Sans Arabic

Programme summary videos use the static Medium and Bold cuts of Noto Sans
Arabic 2.013. They come from the official Noto Arabic release and are
distributed under the SIL Open Font License 1.1. See `NOTO-OFL.txt` in this
directory for the complete license.
