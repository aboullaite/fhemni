# Fonts

## Arabswell

Arabswell Regular is being evaluated locally for Arabic display headings. Its
embedded metadata identifies the family as `arabswell_1`, foundry `MZ73`, with
unrestricted embedding (`fsType = 0`) but no explicit license text. Do not
redistribute the font in a public build until its redistribution license has
been confirmed.

## Tajawal

Fhemni self-hosts Tajawal Regular, Medium and Bold for Arabic body text and
interface controls. Tajawal was designed by Boutros International and is
distributed under the SIL Open Font License 1.1. See `TAJAWAL-OFL.txt` in this
directory for the complete license.

## Noto Sans Arabic

Programme summary videos use the static Medium and Bold cuts of Noto Sans
Arabic 2.013. They come from the official Noto Arabic release and are
distributed under the SIL Open Font License 1.1. See `NOTO-OFL.txt` in this
directory for the complete license.
