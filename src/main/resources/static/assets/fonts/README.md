# Fonts

## Tajawal

Fhemni self-hosts Tajawal Regular, Medium and Bold for Arabic body text and
interface controls. Tajawal was designed by Boutros International and is
distributed under the SIL Open Font License 1.1. See `TAJAWAL-OFL.txt` in this
directory for the complete license.

## Optional TIDO Arabic font

Fhemni supports the TIDO Arabic typeface by Anyone ae®, available from the
[creator’s Behance asset](https://www.behance.net/asset/721845/TIDO-Font).

The font binary is intentionally not redistributed in this source repository.
Behance lists it under the Standard Commercial License, which permits use in
websites and apps but prohibits reselling and standalone use.

After obtaining the font under its original terms, place local copies here as:

```text
tido-regular.otf
tido-bold.otf
```

Those filenames are ignored by Git. When they are absent, the interface uses
the system Arabic font fallback.
